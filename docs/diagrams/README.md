# Documentação de Diagramas

Todas as entidades e seus respectivos diagramas se encontram armazenados no [draw.io](https://app.diagrams.net/):

- **[Entidades](https://app.diagrams.net/...?)**: Visão geral de todas as entidades do sistema.


- **Relações**: Relações entre entidades do sistema.
    - **[User](https://app.diagrams.net/...?)**

## Atualização

Para editar os diagramas:
1. Acesse uma conta com permissão para edição (exemplo: cetecgpt003@gmail.com).
2. Abra o arquivo `.drawio` nos links disponibilizados anteriormente.
3. Edite normalmente os projetos, que são salvos automaticamente.
4. Exporte novamente em PNG/PDF caso deseje.
